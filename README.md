# AntiArchiveScanner

Cross-platform application for automatic scanning of downloaded files and archives on Windows and macOS.

## Installation

### Windows

1. Download **AntiArchiveScanner-Setup.exe**
2. Run the installer.
3. Follow the installation wizard.
4. Launch AntiArchiveScanner.

### macOS

1. Download **AntiArchiveScanner.dmg**
2. Open the DMG.
3. Drag **AntiArchiveScanner.app** to **Applications**.
4. Launch the application.
